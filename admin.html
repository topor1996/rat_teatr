Вход в админку

Пароль задаётся в файле config.php на хостинге.

Сайт работает на GitHub Pages. Админка сохраняет данные прямо в репозиторий, для этого нужен токен GitHub.

Создать: github.com → Settings → Developer settings → Personal access tokens → Fine-grained → Generate. Repository access: только этот репозиторий. Permissions → Contents: Read and write. Токен хранится только в этом браузере.

Театр RAT · админка

Сайт ↗ Голосование ↗

Показы. Прошедшие даты на сайте скрываются сами. «Ссылка на билеты» — страница площадки, где продаются билеты на этот показ; если пусто, берётся ссылка спектакля, а потом общая ссылка из «О театре».

Репертуар. Постер лучше горизонтальный 4:3. Идентификатор нужен, чтобы привязывать показы, менять его после создания не стоит.

Труппа и голосование. Имя, фото и «О себе» показываются на главной в разделе «Труппа». Сцена, описание сцены, ссылка СБП и телефон — на странице голосования.

Где взять ссылку СБП. Актёр в своём банковском приложении открывает «Получить перевод по QR-коду», выбирает вкладку СБП и нажимает «Поделиться» — копирует ссылку вида https://qr.nspk.ru/.... Сбер: профиль → «Получить перевод по QR» → СБП. Т-Банк: «Мой QR» → СБП. Ссылки вида sberbank.com/... работают только у клиентов Сбера.
