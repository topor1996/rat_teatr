Вход в админку

Пароль задаётся в файле config.php на хостинге.

Сайт работает на GitHub Pages. Админка сохраняет данные прямо в репозиторий, для этого нужен токен GitHub.

Создать: github.com → Settings → Developer settings → Personal access tokens → Fine-grained → Generate. Repository access: только этот репозиторий. Permissions → Contents: Read and write. Токен хранится только в этом браузере.

Актёров пока нет — добавьте первого.
Где взять ссылку СБП. Актёр в своём банковском приложении открывает «Получить перевод по QR-коду», выбирает вкладку СБП и нажимает «Поделиться» — копирует ссылку вида https://qr.nspk.ru/.... Сбер: профиль → «Получить перевод по QR» → СБП. Т-Банк: «Мой QR» → СБП. Альфа, ВТБ и другие — раздел «Переводы» → «По QR». Ссылки вида sberbank.com/... работают только у клиентов Сбера, их сюда не нужно.
