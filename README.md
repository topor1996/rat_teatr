# Голосуй рублём — лендинг для театра RAT

Зрители после спектакля голосуют рублём за лучшую сцену: карточки актёров, перевод через СБП из любого банка.

Состав:

- `index.html` — публичная страница.
- `admin.html` — админка: карточки актёров, фото, ссылки СБП, телефоны. Работает в двух режимах: с сервером `server.js` или без сервера на GitHub Pages.
- `data/data.json` — данные спектакля и актёров, `photos/` — фото.
- `server.js` — сервер на Node.js для платного хостинга (не обязателен).
- `Dockerfile` — для хостингов с Docker.

## Бесплатный вариант: GitHub Pages (рекомендуется)

Сервер не нужен. Сайт лежит в репозитории GitHub, а админка сохраняет данные и фото прямо в репозиторий через GitHub API. Ничего не засыпает, ничего не теряется, бесплатно.

Настройка один раз, минут 15:

1. Зарегистрироваться на github.com (если нет аккаунта).
2. Создать репозиторий, например `teatr`, публичный. Загрузить в него файлы `index.html`, `admin.html`, папки `data` и `photos` (кнопка «Add file → Upload files»). `node_modules`, `server.js` и остальное грузить не нужно, но и не помешает.
3. В репозитории: Settings → Pages → Build and deployment → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save. Через минуту сайт откроется по адресу `https://<логин>.github.io/teatr/`.
4. Создать токен для админки: аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
   - Repository access: «Only select repositories» → выбрать `teatr`.
   - Permissions → Repository permissions → Contents: «Read and write».
   - Expiration: максимальный срок (1 год), потом создать новый.
   - Скопировать токен, он показывается один раз.
5. Открыть `https://<логин>.github.io/teatr/admin.html`, ввести репозиторий `<логин>/teatr`, ветку `main` и токен. Токен хранится только в браузере этого устройства.

После «Сохранить» GitHub Pages пересобирает сайт, изменения видны через 1–2 минуты. Фото попадают в папку `photos` репозитория.

Токен даёт право писать в этот один репозиторий, больше ни к чему. Если токен утёк, его можно отозвать в тех же настройках GitHub.

## Вариант с сервером (платный хостинг)

Нужен, только если не хочется зависеть от GitHub. Нужен Node.js 18 или новее.

```bash
npm install
ADMIN_PASSWORD=придумайте-пароль node server.js
```

Сайт: http://localhost:3000, админка: http://localhost:3000/admin.

Если `ADMIN_PASSWORD` не задан, сервер сам сгенерирует пароль и сохранит его в `data/password.txt`. Порт задаётся переменной `PORT`.

## Админка

- Спектакль: театр, название, даты в шапке.
- Каждый актёр: имя, сцена/роль, описание, фото (JPG/PNG/WebP до 8 МБ), ссылка СБП, телефон и банк для запасного способа.
- Кнопки «↑ ↓» меняют порядок карточек, «Удалить» убирает актёра, «+ Добавить актёра» создаёт новую карточку.
- Под полем ссылки СБП подсказка: зелёная «ок», если это `https://qr.nspk.ru/...`, красная, если поле пустое или ссылка другого вида.
- Изменения попадают на сайт после кнопки «Сохранить» внизу экрана.

## Где взять ссылку СБП (qr.nspk.ru)

Каждый актёр делает это один раз в своём банковском приложении:

- **Сбербанк Онлайн**: Профиль (аватар) → «Получить перевод по QR-коду» → вкладка **СБП** → «Поделиться» → скопировать ссылку.
- **Т-Банк**: Главная → «Мой QR» / «Получить перевод по QR» → СБП → «Поделиться ссылкой».
- **Альфа-Банк**: Платежи → «Получить перевод по QR» (СБП) → «Поделиться».
- **ВТБ, Райффайзен, Газпромбанк и др.**: раздел «Переводы» → «Получить перевод по QR (СБП)».

Нужна именно ссылка `https://qr.nspk.ru/...`. Ссылки вида `sberbank.com/sms/...` — внутренний QR Сбера, он работает только у клиентов Сбера.

Пока ссылка не добавлена, кнопка на карточке неактивна и подписана «ссылка СБП ещё не добавлена».

## Хостинг для варианта с сервером

Нужен хостинг с Node.js. Бесплатных с сохранением файлов практически нет: Render бесплатен, но засыпает после 15 минут простоя и стирает загруженные фото при перезапуске. Платные варианты от 170 ₽ в месяц (Amvera) или VPS.

Варианты:

1. **Timeweb Cloud / Beget / Reg.ru** — тариф с Node.js или Docker. Загрузить папку, задать переменные `ADMIN_PASSWORD` и `PORT`, команда запуска `node server.js`.
2. **Любой VPS** (Ubuntu): установить Node.js, скопировать папку, запустить через pm2:
   ```bash
   npm install
   ADMIN_PASSWORD=пароль pm2 start server.js --name teatr
   ```
   Перед сервером поставить nginx или Caddy с HTTPS (Caddy делает сертификат сам).
3. **Docker**:
   ```bash
   docker build -t teatr .
   docker run -d -p 3000:3000 -e ADMIN_PASSWORD=пароль -v teatr-data:/app/data -v teatr-photos:/app/photos teatr
   ```

Важно: папки `data` и `photos` — это всё содержимое сайта. Их нужно бэкапить и не терять при переустановке.

Затем сгенерировать один QR-код на адрес сайта (любой онлайн-генератор) и распечатать его на сиденья вместо пяти сберовских.

## Как страница берёт данные

По порядку: сначала `/api/data` (если запущен `server.js`), затем файл `data/data.json` (GitHub Pages и любой статический хостинг), затем блок «НАСТРОЙКИ» внутри `index.html` (если открыть файл напрямую).
